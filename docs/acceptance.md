## 4. 未覆盖 / 发布前待办

1. **浏览器与真实设备**：Edge、Safari 最新稳定版，以及 iPhone Safari、Android Chrome 真机完整流程尚未验证；本轮只完成 Chrome 与手机视口模拟。
2. **真实中文输入法**：composition 事件模拟不能完全替代搜狗 / 微软拼音等输入法的候选确认行为。
3. **性能测量范围**：目前记录桌面 headless Chrome 下的视图切换耗时；首次内容可用时间（FCP）和手机设备上的 5 次测量尚未单独记录。
4. **视觉还原**：首版需求只规定了简洁浅色风格与可用性约束，未提供像素级交互稿；本实现按约束完成，若后续提供设计稿需要重新对齐视觉细节。
5. **主题视觉核对**：4 种主题已在 headless Chrome 的桌面 1280×720 与手机 390×844 视口截图核对；尚未在 Edge / Safari 和真实手机上核对色差、系统状态栏颜色与户外可读性。
